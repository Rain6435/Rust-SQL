## Logging

> **IMPORTANT!** Replace any sensitive data (e.g. password) before including log data in an issue.

You can enable logging in your `rust-sql.json` configuration file or via the Settings modal:

```json
{
  "log": {
    "console": true,
    "file": true,
    "level": "debug",
    "path": "~/.rust-sql.log"
  }
}
```
